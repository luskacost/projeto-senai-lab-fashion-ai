# Política de segurança

Se você encontrou uma vulnerabilidade neste projeto, **não abra uma issue pública**.

Reporte de forma privada pela aba **Security → Report a vulnerability** deste repositório no
GitHub, descrevendo o problema e, se possível, os passos para reproduzi-lo. A resposta costuma
vir em alguns dias úteis.

Segredos (chaves de API, senhas de acesso) nunca são versionados: ficam em variáveis de ambiente,
conforme `.env.example`.
